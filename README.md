# ClearKhong-backend

## Wanting

1. ตรวจสอบ+ปรับปรุงโค้ดให้ดีขึ้น  
2. แก้จากรวมทุกอย่างอยู่ใน post เป็น order   
3. โค้ด backend บางส่วน เช่น JWT ใช้สำหรับเว็บเท่านั้น แบบแอพจะใช้อีกแบบ ซึ่งข้าพเจ้าไม่รู้ สามารถถาม chatGPT หรือรอ Frontend ก่อนก็ได้
4. การแจ้งเตือนเพิ่มเติม   
5. การอัพเดตสถานะสินค้าหลังจากซื้อไปแล้ว  
6. แก้ไขการยื่นเทรดโดยให้เพิ่มตัวเลือกเทรดจาดเทรดที่เคยสร้าง
