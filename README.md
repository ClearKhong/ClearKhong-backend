# ClearKhong-backend

## Wanting

1. ตรวจสอบ+ปรับปรุงโค้ดให้ดีขึ้น
2. สร้างระบบลบโพสต์หลังจากการกดโพสต์ไปแล้ว (โพสต์นั้นจะลบได้ก๋ต่อเมื่อคนโพสต์เป็นคนลบ ส่วนแอดมินลบได้ทุกโพสต์)  
3. แก้จากรวมทุกอย่างอยู่ใน post เป็น order  
4. แก้ให้ตัวผู้ใช้รายงานตัวเองไม่ได้
5. ระบบรีวิวร้านค้า  
6. โค้ด backend บางส่วน เช่น JWT ใช้สำหรับเว็บเท่านั้น แบบแอพจะใช้อีกแบบ ซึ่งข้าพเจ้าไม่รู้ สามารถถาม chatGPT หรือรอ Frontend ก่อนก็ได้
7. การแจ้งเตือนเพิ่มเติม  
8. แนบสลิปในหน้าจ่ายเงิน  
9. การอัพเดตสถานะสินค้าหลังจากซื้อไปแล้ว  
10. แก้ไขการยื่นเทรดโดยให้เพิ่มตัวเลือก "ยื่นเทรดจากโพสต์ของฉัน"  

## OPTIONAL
1. ปรับปรุงระบบ Authen
2. เพิ่มการกรอกชื่อจริง
3. เพิ่มระบบ login ด้วย email/password

## Run Swagger  
npm install  
npm run dev  
go to http://127.0.0.1:4000/docs
