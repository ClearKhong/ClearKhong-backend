# ClearKhong-backend

## Wanting

1. ตรวจสอบ+ปรับปรุงโค้ดให้ดีขึ้น
2. สร้างระบบลบโพสต์หลังจากการกดโพสต์ไปแล้ว (โพสต์นั้นจะลบได้ก๋ต่อเมื่อคนโพสต์เป็นคนลบ ส่วนแอดมินลบได้ทุกโพสต์)
3. ทำระบบชำระเงินให้มันดีๆ (ตอนนี้มีแค่ mockup QR code แล้วจบเลยแบบโง่ๆ เพราะละไว้ในฐานที่เข้าใจ(ขีเกียจ) )
4. แก้ให้ตัวผู้ใช้รายงานตัวเองไม่ได้
5. โค้ด backend บางส่วน เช่น JWT ใช้สำหรับเว็บเท่านั้น แบบแอพจะใช้อีกแบบ ซึ่งข้าพเจ้าไม่รู้ สามารถถาม chatGPT หรือรอ Frontend ก่อนก็ได้ 

## OPTIONAL
1. ปรับปรุงระบบ Authen
2. เพิ่มการกรอกชื่อจริง/ยืนยันรหัสผ่าน
3. เพิ่มระบบ login ด้วย email/password
4. การแจ้งเตือนเพิ่มเติม
5. ฟังก์ชันเพิ่มเติม เช่น การบริจาค การประมูล หรือตามแต่ท่านคิดได้หรือสมาชิกกลุ่มลงความเห็น
